## Building Bakiano

[Bakiano](https://bakiano.com/en) brings published prices and listings from Venezuelan supermarkets, retailers, and property platforms into one workspace for research and tracking changes.

I build the systems behind it: collection jobs, a historical warehouse, currency-aware transformations, AI enrichment, and the application that makes the data useful.
